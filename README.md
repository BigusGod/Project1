## 📖 О проекте

EcoFact Bot — это веб-сайт, посвящённый одной из самых острых экологических проблем современности — глобальному потеплению. 

Проект создан для того, чтобы в доступной форме рассказать пользователям о проблеме, показать её масштаб и предложить конкретные решения. Сайт сочетает в себе информационный контент и интерактивные инструменты, которые помогают каждому осознать свой личный вклад в состояние планеты.

## ✨ Возможности

- 📚 Общая информация — понятное описание проблемы глобального потепления, его причин и последствий
- 🎲 Случайный факт — кнопка, которая выдаёт случайный факт об экологии и глобальном потеплении
- 🌱 Решения — вместе с фактом пользователь получает практическое решение, которое можно применить в жизни
